Display narration text that updates automatically as the animation progresses. For spoken narration (text-to-speech) or sound on each step, see [Event Hooks](../event-hooks/).

## Default narration text

When `narration` is enabled but you don't pass `narration-text`, the panel shows a sensible mode-aware placeholder so it never renders blank:

| Mode | Default text |
|------|--------------|
| `sequential` | `Press Play to start` |
| `interactive` | `Click a highlighted node to begin` |

Override with the `narration-text` attribute. Pass an empty string explicitly (`narration-text=""`) to suppress the default. Once the player advances to the first step, per-step `note` values take over as before.

```html
<!-- Uses the mode-aware default ("Press Play to start") -->
<mermaid-flow-player controls narration>
  flowchart LR
  A[Build] --> B[Test] --> C[Deploy]
</mermaid-flow-player>

<!-- Custom prompt -->
<mermaid-flow-player controls narration narration-text="Step through the deploy">
  flowchart LR
  A[Build] --> B[Test] --> C[Deploy]
</mermaid-flow-player>

<!-- Explicitly blank -->
<mermaid-flow-player controls narration narration-text="">
  flowchart LR
  A[Build] --> B[Test] --> C[Deploy]
</mermaid-flow-player>
```

## Basic Narration

<LiveExample diagram={`
graph LR
  A[Build] --> B[Test] --> C[Deploy]
`} />

The autoInit mode creates narration containers automatically. For programmatic control:

```html
<div id="diagram" class="mermaid">
graph LR
  A[Build] --> B[Test] --> C[Deploy]
</div>
<div id="narration"></div>

<script type="module">
  import { createFlowPlayer } from 'https://cdn.jsdelivr.net/npm/mermaid-flow-player@latest/index.js';

  const diagram = document.getElementById('diagram');
  const player = createFlowPlayer({
    root: diagram,
    source: diagram.textContent,
    narrationTarget: '#narration'  // CSS selector or element
  });

  await player.ready();
  await player.play([
    { type: 'node', id: 'A', note: 'Building the application...' },
    { type: 'node', id: 'B', note: 'Running test suite...' },
    { type: 'node', id: 'C', note: 'Deploying to production!' },
  ]);
</script>
```

**Web Component:**

```html
<script src="https://cdn.jsdelivr.net/npm/mermaid-flow-player@latest/mermaid-flow-player.element.js"></script>

<!-- narration is on by default; use narration="false" to disable -->
<mermaid-flow-player controls narration theme="light">
graph LR
  A[Build] --> B[Test] --> C[Deploy]
</mermaid-flow-player>
```

## Narration with autoInit

The simplest way — autoInit creates a narration element for you:

```html
<script type="module">
  import { autoInit } from 'https://cdn.jsdelivr.net/npm/mermaid-flow-player@latest/auto-init.js';

  autoInit({
    selector: '.mermaid',
    narration: true  // Renders the caption area (default)
  });
</script>
```

## Narration in the diagram source

Write the script in the diagram itself with `%% narrate`. It travels with the
fenced code block, so narration survives copy-paste and a coding agent can emit
a diagram that explains its own flow:

```html
<div class="mermaid">
flowchart LR
  A[Build] --> B[Test] --> C[Deploy]
  %% narrate A: First we compile the project and cache the result.
  %%   Nothing else runs until this succeeds.
  %% narrate B: Then the suite runs against the fresh build.
  %% narrate C: Finally we ship it.
</div>
```

A `%%` line indented by two or more spaces continues the previous directive, so
long narration can wrap. The script wins over the derived node label everywhere
at once: captions, voice, the chapter rail, the transcript and the VTT track.

On a sequence diagram an id-less `%% narrate:` attaches to the message above
it, the same way `Note over` does.

Press Next on this one and read the caption: the text is the script, not the
box labels.

This works identically on upgraded `.mermaid` blocks and on
`<mermaid-flow-player>` markup — the upgrade moves the source across intact.

:::caution
If Mermaid renders a block before the player sees it, the source (and the
script with it) is gone. Initialize Mermaid with `startOnLoad: false`, or don't
load it at all and let the player fetch it.
:::

## Step Notes

Each step in a scenario can have a `note` property:

```javascript
await player.play([
  { type: 'node', id: 'Start', state: 'active', note: 'Welcome! Let\'s begin.' },
  { type: 'wait', ms: 500 },
  { type: 'node', id: 'Process', state: 'active', note: 'Processing your request...' },
  { type: 'node', id: 'Check', state: 'warning', note: 'Validating the results.' },
  { type: 'node', id: 'Done', state: 'success', note: 'All done! Everything passed.' },
]);
```

## Narration with Hooks

Get full control over narration display:

```javascript
const diagram = document.getElementById('diagram');
const player = createFlowPlayer({
  root: diagram,
  source: diagram.textContent,
  hooks: {
    onStepStart: (step, narration) => {
      if (narration) {
        // Custom narration display
        document.getElementById('custom-narration').innerHTML = `
          <strong>Step:</strong> ${step.id || 'wait'}<br>
          <em>${narration}</em>
        `;
      }
    }
  }
});
```

## Narration Styling

The default narration container has the class `mermaid-flow-narration`:

```css
.mermaid-flow-narration {
  margin-top: 10px;
  padding: 10px;
  background: #f0f0f0;
  border-radius: 4px;
  font-size: 14px;
}
```

Customize with CSS variables:

```css
:root {
  --mf-narration-bg: #1a1a2e;
  --mf-narration-text: #fff;
  --mf-narration-padding: 12px;
  --mf-narration-font-size: 16px;
}
```

## Accessibility

Narration elements created by autoInit include ARIA attributes:

```html
<div class="mermaid-flow-narration"
     role="status"
     aria-live="polite"
     aria-atomic="true"
     aria-label="Animation narration">
  Click play to start animation
</div>
```

This ensures screen readers announce narration updates.
